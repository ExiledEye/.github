# Support Guide

Looking for help? Please use the channels outlined below to find answers or get assistance with our projects.

## 📌 1. Check the Documentation
Before reaching out, please thoroughly review the project's `README.md`, inline code comments, dedicated documentation files and/or wiki section within the specific repository. Most configuration and setup questions are covered there.

## 💬 2. Community & General Support
Please **do not open an issue** for general questions, configuration assistance, or setup troubleshooting. Instead, use the following channels:
* **GitHub Discussions:** If enabled on the repository, check the **Q&A** or **General** categories. You can search past discussions or open a new thread.
* **Alternative Channels:** You can also directly contact me via discord: exiled_eye.

## 🐛 3. Reporting Technical Bugs
If you have verified that the issue is a genuine bug inherent to the codebase (and not a local setup or environment configuration error):
1. Search the repository's active and closed issues to see if it has already been addressed.
2. Open a new issue using the **Bug Report** template, providing all requested logs and technical context.
